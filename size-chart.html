测量方法

下单前建议按以下方法准确测量，可获得最贴近的尺码推荐。下方示意图为许乐自绘 SVG，便于直观理解每个部位的测量起止点。

1. 鞋履：脚长 / 脚宽 / 脚围测量

脚长 / 脚宽测量

步骤：赤脚踩 A4 白纸，脚后跟贴墙，最长脚趾前端画一条竖线。脚长 = 墙到线的水平距离；脚宽 = 脚掌最宽处左右两点的水平距离。

  • 建议下午 4-6 点测量（脚略胀）
  • 双脚分别测，取较大值
  • 穿袜者按袜子厚度 +0.5cm
  • 脚长每差 0.5cm 对应 1 码
  • 脚宽 > 9.5cm 建议选 3E/4E 楦宽

脚围（跖围）测量

步骤：用软皮尺过脚背最宽处（前脚掌骨头下方）水平环绕一周，松紧以贴合皮肤但不勒紧为准。

  • 脚围 = 前脚掌周长
  • 标准男款脚围 24-26cm，女款 22-23.5cm
  • 脚围偏大建议大半码 + 加宽楦
  • 高脚背者选系带款，避免一脚蹬

2. 服饰：胸围 / 腰围 / 臀围 / 肩宽测量

胸围 / 腰围 / 臀围

胸围：穿薄衫，皮尺过乳头点（BP 点）水平环绕一周，松紧以能插一根手指为宜，呼气末测量，取三次平均。

腰围：站直放松，皮尺过腰部最细处（约肚脐上 2-3cm）水平环绕一周，不要吸气收腹。

臀围：双脚并拢，皮尺过臀部最丰满处（耻骨后 18-20cm）水平环绕一周。

  • 所有数据单位为 CM
  • 皮尺保持水平，不可前倾后翘
  • 肩宽另测：后背两肩峰点距离

平铺测量（参考成衣）

步骤：将衣服平铺桌面，量以下数据：肩宽（两肩缝线间距离）、胸围平铺（腋下 2cm 处左右两点距离，×2 即胸围）、衣长（肩缝中点到下摆）。

  • 平铺数据更接近成衣实测
  • 弹性面料拉伸后测
  • 裤长 = 腰头到裤脚外缝
  • 袖长 = 肩缝到袖口

3. 箱包：长 / 宽 / 高 / 容量测量

外尺寸长 × 宽 × 高

步骤：将包放平，量最长边为「长」，前后厚度为「宽」，上下为「高」。许乐商品页均标注「外尺寸」，选购电脑包需留 1-2cm 余量。

  • 单位 CM，按外轮廓量
  • 含提手高度另标
  • 容量（L）= 长×宽×高÷1000（近似）
  • 笔电包需 ≥ 笔电 + 2cm

背带 / 提手长度

步骤：背带从五金扣一端沿带身量到另一端，含可调范围。提手则量两五金扣之间直线距离。单肩背负建议肩高 30-40cm，斜挎建议 60-100cm。

  • 背带可调范围标注最大值
  • 双肩背负需肩带 70cm 以上
  • 提手高度影响手提舒适度
  • 挂件负重后背带会延伸 1-2cm

4. 饰品：项链 / 手链 / 戒指测量

项链链长选择

步骤：用软皮尺从颈后第七颈椎（脖子后部凸起骨）为起点，沿前胸下垂到目标位置，长度即所需链长。

  • 锁骨链 35-38cm，紧贴颈根
  • 标准女款 40-42cm，落锁骨下
  • 毛衣链 50-55cm，过胸前
  • 挂坠款建议 +2-3cm

戒指内径 / 周长

方法一（纸条法）：用细纸条绕手指根部一圈，标记后量长度即周长（C）。

方法二（直尺法）：用直尺量现有戒指内圈直径（Ø），周长 C = Ø × 3.14。

  • 建议晚上测量（手指略胀）
  • 关节比指根粗需按关节量
  • 925 银开口款可调 2 号
  • 对照表见上方「戒指号数对照」
